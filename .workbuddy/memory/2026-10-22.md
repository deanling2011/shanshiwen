# 2026-10-22 工作日志

## 山人拾遗（shanwenji）每日文集归档系统

- 用户需求：把 `shanshi_cleaned.xlsx`（17798 条 山人微博文集，Date+Content 两列，2011-08-14 ~ 2024-09-10，覆盖全部 366 个月日）做成「历史上的今天」每日归档系统。
- 新建 GitHub 仓库 `deanling2011/shanwenji`（public）。

### 架构
- 数据：按「月-日」拆分 366 个 `data/MM-DD.json` + `index.json`，按年份分组，组内保持原序（即时间序）。
- 网页：`index.html` 纯静态，深色主题，日历导航 + 今日卡片 + 点日期查看历年文集。托管 GitHub Pages（https://deanling2011.github.io/shanwenji/）。
- 每日自动化：GitHub Actions `daily.yml`，cron `10 0 * * *`（北京时间 08:10），build_daily.py 生成 archive/MM-DD.md + img/MM-DD-YYYY.png（分年图）+ img/MM-DD.png（总览），再 push_daily.py 推 PushDeer，最后 git commit 归档。
- 图片生成：Pillow，Windows 用 msyh.ttc，Linux(CI) 用 Noto CJK，脚本自动映射。

### 关键决策
- CDN：jsDelivr 已退化为 301 重定向到 raw（不再缓存），改用 **ghproxy**（https://ghproxy.net/https://raw.githubusercontent.com/...）。用户确认图片+文字都用 ghproxy。
- 文字版底部去掉"数据来源"等尾注（用户要求）。
- 推送：PushDeer markdown 卡片，pushkey 存 GitHub secret `PUSHDEER_KEY`（值：PDU39735...）。
- 文件命名固定为 MM-DD（如 10-22.png），避免"内容不是当天"的历史问题。

### 待办/注意
- GitHub token（fine-grained）需逐步授权：Administration(建仓)、Contents:write(推送)、Pages:write(启用 Pages)、Secrets(配 secret)。
- 本机 git push 需绕过代理：`GIT_SSL_NO_VERIFY=1 git -c http.proxy= -c https.proxy= push`。
